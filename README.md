# Resolution Bingo

**Resolution Bingo** is a New Year's resolution tracker built as a 5×5 bingo card. Instead of a forgotten list, your resolutions become a game — mark off each goal as you complete it throughout the year and aim for bingo.

## Features

- Add up to 24 custom resolutions to fill the grid (the center square is a free space)
- Tap any square to mark it as completed, stamped with the date you achieved it
- Edit mode lets you rewrite resolutions, shuffle the grid, or start fresh with a new card
- Bingo detection across rows, columns, and diagonals — with a celebration when you complete the full card
- Export your card as an image or PDF to share your progress
- Fully responsive — works on mobile, tablet, and desktop
